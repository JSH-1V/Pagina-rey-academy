# Rey Academy

Landing page de Rey Academy — academia de formación empresarial para dueños de carnicerías en Latinoamérica. React + Vite + TypeScript + Tailwind CSS v4.

## Requisitos

- Node.js 20 o superior

## Desarrollo local

```bash
npm install
npm run dev
```

Levanta el servidor en `http://localhost:3000`.

## Build de producción

```bash
npm run build
```

Genera el sitio estático en `dist/`.
